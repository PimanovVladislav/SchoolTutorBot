Описание базы данных tutor_bot
================================

СУБД: MySQL, charset utf8mb4.
ORM: SQLAlchemy 2 (модели — tutor_bot/db/models.py).
При старте бота вызывается apply_schema(): Base.metadata.create_all() создаёт
отсутствующие таблицы, затем выполняются ALTER для колонок, добавленных позже.

Таблицы создаются автоматически. SQL ниже — эталон «с нуля», если таблицы нет.
Типы BOOL в MySQL хранятся как TINYINT(1). Даты — DATETIME (naive UTC).

Порядок создания учитывает внешние ключи.


Зависимости (кто на кого ссылается)
-----------------------------------
grades                  — справочник, ни от кого не зависит
subjects                — справочник предметов
tracks                  → subjects
topics                  → tracks
topic_theories          → topics
problems                → topics (topic_id, source_topic_id)
problem_hints           → problems
problem_solutions       → problems
users                   → tracks, topics
subscriptions           → users
learning_sessions       → users, topics
attempts                → users, learning_sessions, problems
topic_progress          → users, topics
assessment_attempts     → users, topics
assessment_answers      → assessment_attempts, problems
user_problem_stats      → users, problems


1. grades
---------
Назначение: список классов, которые можно выбрать при онбординге и в настройках.
Что хранит: номер класса (PK = само значение, например 5, 6, 7).

Поля:
  grade  INT  PK  — номер класса. AUTO_INCREMENT в DDL от SQLAlchemy есть,
                    но приложение вставляет конкретный номер класса.

CREATE TABLE IF NOT EXISTS grades (
  grade INT NOT NULL AUTO_INCREMENT,
  PRIMARY KEY (grade)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


2. subjects
-----------
Назначение: учебный предмет (математика и т.п.).
Что хранит: идентификатор, машинный slug, человекочитаемое название, флаг активности.

Поля:
  id         INT          PK AUTO_INCREMENT
  slug       VARCHAR(64)  UNIQUE NOT NULL  — машинное имя, например math
  title      VARCHAR(255) NOT NULL         — «Математика»
  is_active  TINYINT(1)   NOT NULL DEFAULT 1

CREATE TABLE IF NOT EXISTS subjects (
  id INT NOT NULL AUTO_INCREMENT,
  slug VARCHAR(64) NOT NULL,
  title VARCHAR(255) NOT NULL,
  is_active TINYINT(1) NOT NULL DEFAULT 1,
  PRIMARY KEY (id),
  UNIQUE KEY slug (slug)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


3. tracks
---------
Назначение: направление внутри предмета (школьная программа, ОГЭ, ЕГЭ, доп.).
Что хранит: привязку к предмету и название направления.
Зависимости: subject_id → subjects.id ON DELETE CASCADE.
Уникальность: (subject_id, slug).

Поля:
  id          INT          PK AUTO_INCREMENT
  subject_id  INT          NOT NULL FK → subjects.id
  slug        VARCHAR(64)  NOT NULL  — например school
  title       VARCHAR(255) NOT NULL  — «Школьная программа»

CREATE TABLE IF NOT EXISTS tracks (
  id INT NOT NULL AUTO_INCREMENT,
  subject_id INT NOT NULL,
  slug VARCHAR(64) NOT NULL,
  title VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_tracks_subject_slug (subject_id, slug),
  CONSTRAINT tracks_ibfk_1 FOREIGN KEY (subject_id) REFERENCES subjects (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


4. topics
---------
Назначение: тема курса в конкретном классе и направлении.
Что хранит: название, краткое описание, черновик теории (дублируется в topic_theories),
размер проверочной, номер темы для ученика (sort_order).
Зависимости: track_id → tracks.id ON DELETE CASCADE.
Уникальность: (track_id, grade, slug).
Индекс: ix_topics_track_grade_order (track_id, grade, sort_order).

Поля:
  id                   INT           PK AUTO_INCREMENT
  track_id             INT           NOT NULL FK → tracks.id
  grade                INT           NOT NULL  — класс, к которому относится тема
  slug                 VARCHAR(128)  NOT NULL
  title                VARCHAR(255)  NOT NULL
  summary              VARCHAR(512)  NOT NULL DEFAULT ''
  theory               TEXT          NOT NULL DEFAULT ''  — устаревшее поле; живые редакции в topic_theories
  theory_kind          VARCHAR(16)   NOT NULL DEFAULT 'text'  — text | photo
  theory_image_path    VARCHAR(512)  NULL
  assessment_required  INT           NOT NULL DEFAULT 3  — сколько заданий в проверочной
  sort_order           INT           NOT NULL DEFAULT 0  — номер темы для ученика в классе (1, 2, 3…)

CREATE TABLE IF NOT EXISTS topics (
  id INT NOT NULL AUTO_INCREMENT,
  track_id INT NOT NULL,
  grade INT NOT NULL,
  slug VARCHAR(128) NOT NULL,
  title VARCHAR(255) NOT NULL,
  summary VARCHAR(512) NOT NULL DEFAULT '',
  theory TEXT NOT NULL,
  theory_kind VARCHAR(16) NOT NULL DEFAULT 'text',
  theory_image_path VARCHAR(512) NULL,
  assessment_required INT NOT NULL DEFAULT 3,
  sort_order INT NOT NULL DEFAULT 0,
  PRIMARY KEY (id),
  UNIQUE KEY uq_topics_track_grade_slug (track_id, grade, slug),
  KEY ix_topics_track_grade_order (track_id, grade, sort_order),
  CONSTRAINT topics_ibfk_1 FOREIGN KEY (track_id) REFERENCES tracks (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


5. topic_theories
-----------------
Назначение: редакции объяснения темы («Всё ещё непонятно» листает edition).
Что хранит: текст/фото теории для конкретной редакции.
Зависимости: topic_id → topics.id ON DELETE CASCADE.
Уникальность: uq_topic_theories_edition (topic_id, edition).
Индекс: ix_topic_theories_topic (topic_id, edition).

Поля:
  id             INT           PK AUTO_INCREMENT
  topic_id       INT           NOT NULL FK → topics.id
  edition        INT           NOT NULL DEFAULT 1  — номер редакции (1, 2, …)
  edition_count  INT           NOT NULL DEFAULT 1  — сколько редакций всего (дублируется в строках)
  body           TEXT          NOT NULL DEFAULT ''
  kind           VARCHAR(16)   NOT NULL DEFAULT 'text'  — text | photo
  image_path     VARCHAR(512)  NULL

CREATE TABLE IF NOT EXISTS topic_theories (
  id INT NOT NULL AUTO_INCREMENT,
  topic_id INT NOT NULL,
  edition INT NOT NULL DEFAULT 1,
  edition_count INT NOT NULL DEFAULT 1,
  body TEXT NOT NULL,
  kind VARCHAR(16) NOT NULL DEFAULT 'text',
  image_path VARCHAR(512) NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_topic_theories_edition (topic_id, edition),
  KEY ix_topic_theories_topic (topic_id, edition),
  CONSTRAINT topic_theories_ibfk_1 FOREIGN KEY (topic_id) REFERENCES topics (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


6. problems
-----------
Назначение: банк заданий темы.
Что хранит: условие, правильный ответ, тип проверки, сложность, подсказку/разбор (черновик;
живые редакции — в problem_hints / problem_solutions).
Зависимости:
  topic_id        → topics.id ON DELETE CASCADE  — тема, где задание выдаётся
  source_topic_id → topics.id                    — исходная тема для закрепления (может быть NULL)
Индекс: ix_problems_topic_kind (topic_id, kind, sort_order).

Поля:
  id               INT           PK AUTO_INCREMENT
  topic_id         INT           NOT NULL FK
  source_topic_id  INT           NULL FK → topics.id
  kind             VARCHAR(32)   NOT NULL  — training | assessment | reinforcement
  answer_type      VARCHAR(32)   NOT NULL  — number | fraction | numbers | text | choice
  prompt           TEXT          NOT NULL  — условие (HTML/текст)
  correct_answer   VARCHAR(255)  NOT NULL
  choices          TEXT          NULL      — варианты для choice, если нужны
  hint             TEXT          NOT NULL DEFAULT ''
  solution         TEXT          NOT NULL DEFAULT ''
  difficulty       INT           NOT NULL DEFAULT 1  — 1 лёгкий, 2 средний, 3 сложный
  sort_order       INT           NOT NULL DEFAULT 0
  needs_review     TINYINT(1)    NOT NULL DEFAULT 0  — ученик пожаловался на задание

CREATE TABLE IF NOT EXISTS problems (
  id INT NOT NULL AUTO_INCREMENT,
  topic_id INT NOT NULL,
  source_topic_id INT NULL,
  kind VARCHAR(32) NOT NULL,
  answer_type VARCHAR(32) NOT NULL,
  prompt TEXT NOT NULL,
  correct_answer VARCHAR(255) NOT NULL,
  choices TEXT NULL,
  hint TEXT NOT NULL,
  solution TEXT NOT NULL,
  difficulty INT NOT NULL DEFAULT 1,
  sort_order INT NOT NULL DEFAULT 0,
  needs_review TINYINT(1) NOT NULL DEFAULT 0,
  PRIMARY KEY (id),
  KEY ix_problems_topic_kind (topic_id, kind, sort_order),
  CONSTRAINT problems_ibfk_1 FOREIGN KEY (topic_id) REFERENCES topics (id) ON DELETE CASCADE,
  CONSTRAINT problems_ibfk_2 FOREIGN KEY (source_topic_id) REFERENCES topics (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


7. problem_hints
----------------
Назначение: редакции подсказок к заданию.
Зависимости: problem_id → problems.id ON DELETE CASCADE.
Уникальность: uq_problem_hints_edition (problem_id, edition).
Индекс: ix_problem_hints_problem (problem_id, edition).

Поля:
  id             INT   PK AUTO_INCREMENT
  problem_id     INT   NOT NULL FK
  edition        INT   NOT NULL DEFAULT 1
  edition_count  INT   NOT NULL DEFAULT 1
  body           TEXT  NOT NULL DEFAULT ''

CREATE TABLE IF NOT EXISTS problem_hints (
  id INT NOT NULL AUTO_INCREMENT,
  problem_id INT NOT NULL,
  edition INT NOT NULL DEFAULT 1,
  edition_count INT NOT NULL DEFAULT 1,
  body TEXT NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_problem_hints_edition (problem_id, edition),
  KEY ix_problem_hints_problem (problem_id, edition),
  CONSTRAINT problem_hints_ibfk_1 FOREIGN KEY (problem_id) REFERENCES problems (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


8. problem_solutions
--------------------
Назначение: редакции разбора (решения) задания.
Зависимости: problem_id → problems.id ON DELETE CASCADE.
Уникальность: uq_problem_solutions_edition (problem_id, edition).
Индекс: ix_problem_solutions_problem (problem_id, edition).

Поля:
  id             INT   PK AUTO_INCREMENT
  problem_id     INT   NOT NULL FK
  edition        INT   NOT NULL DEFAULT 1
  edition_count  INT   NOT NULL DEFAULT 1
  body           TEXT  NOT NULL DEFAULT ''

CREATE TABLE IF NOT EXISTS problem_solutions (
  id INT NOT NULL AUTO_INCREMENT,
  problem_id INT NOT NULL,
  edition INT NOT NULL DEFAULT 1,
  edition_count INT NOT NULL DEFAULT 1,
  body TEXT NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_problem_solutions_edition (problem_id, edition),
  KEY ix_problem_solutions_problem (problem_id, edition),
  CONSTRAINT problem_solutions_ibfk_1 FOREIGN KEY (problem_id) REFERENCES problems (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


9. users
--------
Назначение: аккаунт ученика/админа в Telegram.
Что хранит: профиль, выбранный класс и направление, текущую тему.
id — Telegram user id (приложение вставляет его явно, не генерирует).
Зависимости: track_id → tracks.id; current_topic_id → topics.id (без CASCADE).

Поля:
  id                BIGINT        PK  — Telegram user id
  username          VARCHAR(255)  NULL
  first_name        VARCHAR(255)  NULL
  last_name         VARCHAR(255)  NULL
  grade             INT           NULL  — выбранный класс
  track_id          INT           NULL  FK → tracks.id
  current_topic_id  INT           NULL  FK → topics.id
  role              VARCHAR(32)   NOT NULL DEFAULT 'student'  — student | admin
  created_at        DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP

CREATE TABLE IF NOT EXISTS users (
  id BIGINT NOT NULL,
  username VARCHAR(255) NULL,
  first_name VARCHAR(255) NULL,
  last_name VARCHAR(255) NULL,
  grade INT NULL,
  track_id INT NULL,
  current_topic_id INT NULL,
  `role` VARCHAR(32) NOT NULL DEFAULT 'student',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  CONSTRAINT users_ibfk_1 FOREIGN KEY (track_id) REFERENCES tracks (id),
  CONSTRAINT users_ibfk_2 FOREIGN KEY (current_topic_id) REFERENCES topics (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


10. subscriptions
-----------------
Назначение: доступ ученика по времени (триал, оплата, выдача админом).
Что хранит: период и статус подписки.
Зависимости: user_id → users.id ON DELETE CASCADE.
Индекс: ix_subscriptions_user_ends (user_id, ends_at).

Поля:
  id                   INT           PK AUTO_INCREMENT
  user_id              BIGINT        NOT NULL FK
  starts_at            DATETIME      NOT NULL
  ends_at              DATETIME      NOT NULL
  status               VARCHAR(32)   NOT NULL DEFAULT 'active'  — active | revoked
  source               VARCHAR(32)   NOT NULL DEFAULT 'admin'   — admin | stars
  provider_payment_id  VARCHAR(255)  NULL  — id платежа провайдера (Stars и т.п.)

CREATE TABLE IF NOT EXISTS subscriptions (
  id INT NOT NULL AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  starts_at DATETIME NOT NULL,
  ends_at DATETIME NOT NULL,
  status VARCHAR(32) NOT NULL DEFAULT 'active',
  source VARCHAR(32) NOT NULL DEFAULT 'admin',
  provider_payment_id VARCHAR(255) NULL,
  PRIMARY KEY (id),
  KEY ix_subscriptions_user_ends (user_id, ends_at),
  CONSTRAINT subscriptions_ibfk_1 FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


11. learning_sessions
---------------------
Назначение: сессия прохождения темы (теория / тренировка). Не путать с проверочной:
проверочная живёт в assessment_attempts.
Зависимости: user_id → users.id ON DELETE CASCADE; topic_id → topics.id.
Индекс: ix_sessions_user_active (user_id, status).

Поля:
  id           INT          PK AUTO_INCREMENT
  user_id      BIGINT       NOT NULL FK
  topic_id     INT          NOT NULL FK
  stage        VARCHAR(32)  NOT NULL DEFAULT 'theory'  — theory | training | assessment | reinforcement
  status       VARCHAR(32)  NOT NULL DEFAULT 'active'  — active | finished | abandoned
  started_at   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP
  finished_at  DATETIME     NULL

CREATE TABLE IF NOT EXISTS learning_sessions (
  id INT NOT NULL AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  topic_id INT NOT NULL,
  stage VARCHAR(32) NOT NULL DEFAULT 'theory',
  status VARCHAR(32) NOT NULL DEFAULT 'active',
  started_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  finished_at DATETIME NULL,
  PRIMARY KEY (id),
  KEY ix_sessions_user_active (user_id, status),
  CONSTRAINT learning_sessions_ibfk_1 FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
  CONSTRAINT learning_sessions_ibfk_2 FOREIGN KEY (topic_id) REFERENCES topics (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


12. attempts
------------
Назначение: попытки ответа в рамках learning_sessions (тренировка / закрепление).
Оценка проверочной сюда не пишется — см. assessment_answers.
Зависимости:
  user_id    → users.id ON DELETE CASCADE
  session_id → learning_sessions.id ON DELETE CASCADE
  problem_id → problems.id
Индекс: ix_attempts_session (session_id, problem_id).

Поля:
  id          INT           PK AUTO_INCREMENT
  user_id     BIGINT        NOT NULL FK
  session_id  INT           NOT NULL FK
  problem_id  INT           NOT NULL FK
  submitted   VARCHAR(255)  NOT NULL DEFAULT ''
  is_correct  TINYINT(1)    NOT NULL DEFAULT 0
  used_help   TINYINT(1)    NOT NULL DEFAULT 0  — смотрел разбор
  created_at  DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP

CREATE TABLE IF NOT EXISTS attempts (
  id INT NOT NULL AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  session_id INT NOT NULL,
  problem_id INT NOT NULL,
  submitted VARCHAR(255) NOT NULL DEFAULT '',
  is_correct TINYINT(1) NOT NULL DEFAULT 0,
  used_help TINYINT(1) NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY ix_attempts_session (session_id, problem_id),
  CONSTRAINT attempts_ibfk_1 FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
  CONSTRAINT attempts_ibfk_2 FOREIGN KEY (session_id) REFERENCES learning_sessions (id) ON DELETE CASCADE,
  CONSTRAINT attempts_ibfk_3 FOREIGN KEY (problem_id) REFERENCES problems (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


13. topic_progress
------------------
Назначение: сводный прогресс ученика по теме (теория, тренировка, лучшая оценка).
Зависимости: user_id → users.id ON DELETE CASCADE; topic_id → topics.id ON DELETE CASCADE.
Уникальность: (user_id, topic_id).

Поля:
  id                      INT          PK AUTO_INCREMENT
  user_id                 BIGINT       NOT NULL FK
  topic_id                INT          NOT NULL FK
  theory_done             TINYINT(1)   NOT NULL DEFAULT 0
  training_done           TINYINT(1)   NOT NULL DEFAULT 0
  assessment_score        FLOAT        NULL  — процент по последней/учтённой проверочной
  best_grade              VARCHAR(8)   NULL  — лучшая оценка: 3 | 4 | 5 | 5+ | «не сдано»
  reinforcement_correct   INT          NOT NULL DEFAULT 0
  reinforcement_total     INT          NOT NULL DEFAULT 0
  mastery                 VARCHAR(32)  NOT NULL DEFAULT 'not_started'
                          — not_started | learning | needs_practice | confident | mastered
  last_activity_at        DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP  — обновляется при изменениях

CREATE TABLE IF NOT EXISTS topic_progress (
  id INT NOT NULL AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  topic_id INT NOT NULL,
  theory_done TINYINT(1) NOT NULL DEFAULT 0,
  training_done TINYINT(1) NOT NULL DEFAULT 0,
  assessment_score FLOAT NULL,
  best_grade VARCHAR(8) NULL,
  reinforcement_correct INT NOT NULL DEFAULT 0,
  reinforcement_total INT NOT NULL DEFAULT 0,
  mastery VARCHAR(32) NOT NULL DEFAULT 'not_started',
  last_activity_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uq_topic_progress_user_topic (user_id, topic_id),
  CONSTRAINT topic_progress_ibfk_1 FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
  CONSTRAINT topic_progress_ibfk_2 FOREIGN KEY (topic_id) REFERENCES topics (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


14. assessment_attempts
-----------------------
Назначение: попытка проверочной работы по теме (набор заданий, дедлайн 1 день, оценка).
Что хранит: сроки, статус, итог, список id заданий (случайная выборка из банка),
id сообщения-описания в Telegram.
Зависимости: user_id → users.id ON DELETE CASCADE; topic_id → topics.id ON DELETE CASCADE.
Индекс: ix_assessment_user_topic (user_id, topic_id, status).

Поля:
  id                INT          PK AUTO_INCREMENT
  user_id           BIGINT       NOT NULL FK
  topic_id          INT          NOT NULL FK
  started_at        DATETIME     NOT NULL
  finished_at       DATETIME     NULL
  deadline_at       DATETIME     NOT NULL
  status            VARCHAR(32)  NOT NULL DEFAULT 'in_progress'
                    — in_progress | completed | expired
  correct_count     INT          NULL  — заполняется при сдаче
  total             INT          NOT NULL DEFAULT 0  — число заданий в этой работе
  grade             VARCHAR(8)   NULL  — 3 | 4 | 5 | 5+ | «не сдано»
  problem_ids       TEXT         NOT NULL DEFAULT ''  — id заданий через запятую, порядок выдачи
  panel_message_id  INT          NULL  — Telegram message_id описания проверочной

CREATE TABLE IF NOT EXISTS assessment_attempts (
  id INT NOT NULL AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  topic_id INT NOT NULL,
  started_at DATETIME NOT NULL,
  finished_at DATETIME NULL,
  deadline_at DATETIME NOT NULL,
  status VARCHAR(32) NOT NULL DEFAULT 'in_progress',
  correct_count INT NULL,
  total INT NOT NULL DEFAULT 0,
  grade VARCHAR(8) NULL,
  problem_ids TEXT NOT NULL,
  panel_message_id INT NULL,
  PRIMARY KEY (id),
  KEY ix_assessment_user_topic (user_id, topic_id, status),
  CONSTRAINT assessment_attempts_ibfk_1 FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
  CONSTRAINT assessment_attempts_ibfk_2 FOREIGN KEY (topic_id) REFERENCES topics (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


15. assessment_answers
----------------------
Назначение: ответы ученика по заданиям конкретной проверочной.
is_correct выставляется только при завершении работы (не в момент ввода).
Зависимости: attempt_id → assessment_attempts.id ON DELETE CASCADE; problem_id → problems.id.
Уникальность: (attempt_id, problem_id).

Поля:
  id          INT           PK AUTO_INCREMENT
  attempt_id  INT           NOT NULL FK
  problem_id  INT           NOT NULL FK
  sort_order  INT           NOT NULL DEFAULT 1  — номер задания в работе (1..N)
  submitted   VARCHAR(255)  NOT NULL DEFAULT ''
  is_correct  TINYINT(1)    NULL  — NULL пока работа не сдана

CREATE TABLE IF NOT EXISTS assessment_answers (
  id INT NOT NULL AUTO_INCREMENT,
  attempt_id INT NOT NULL,
  problem_id INT NOT NULL,
  sort_order INT NOT NULL DEFAULT 1,
  submitted VARCHAR(255) NOT NULL DEFAULT '',
  is_correct TINYINT(1) NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_assessment_answers_attempt_problem (attempt_id, problem_id),
  CONSTRAINT assessment_answers_ibfk_1 FOREIGN KEY (attempt_id) REFERENCES assessment_attempts (id) ON DELETE CASCADE,
  CONSTRAINT assessment_answers_ibfk_2 FOREIGN KEY (problem_id) REFERENCES problems (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


16. user_problem_stats
----------------------
Назначение: когда ученик в последний раз решал конкретное задание (кулдаун тренировки).
Зависимости: user_id → users.id ON DELETE CASCADE; problem_id → problems.id ON DELETE CASCADE.
Уникальность: (user_id, problem_id).

Поля:
  id               INT       PK AUTO_INCREMENT
  user_id          BIGINT    NOT NULL FK
  problem_id       INT       NOT NULL FK
  last_solved_at   DATETIME  NULL  — последняя верная попытка
  last_attempt_at  DATETIME  NULL  — любая последняя попытка

CREATE TABLE IF NOT EXISTS user_problem_stats (
  id INT NOT NULL AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  problem_id INT NOT NULL,
  last_solved_at DATETIME NULL,
  last_attempt_at DATETIME NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_user_problem_stats_user_problem (user_id, problem_id),
  CONSTRAINT user_problem_stats_ibfk_1 FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
  CONSTRAINT user_problem_stats_ibfk_2 FOREIGN KEY (problem_id) REFERENCES problems (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
