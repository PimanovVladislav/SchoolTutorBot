# Tutor Bot

Телеграм-репетитор по школьным предметам. Сейчас в контенте — математика 6–9 классов: разбор темы, тренировка, проверочная и закрепление.

Старый бот напоминаний о днях рождения заменён этой системой. Архитектура рассчитана на рост: новые предметы, треки ОГЭ/ЕГЭ и много учеников без переписывания ядра.

## Что умеет сейчас

- Онбординг: ученик выбирает класс, программа подбирается автоматически.
- Урок по теме: теория → тренировочные задачи → проверочная с оценкой.
- После двух неверных ответов появляется кнопка разбора.
- Оценка темы: верно без помощи = 1, после разбора = 0.5, неверно = 0.
- Закрепление: задачи из уже сданных тем всплывают перед новой темой.
- Прогресс по каждой теме (уровень понимания + процент проверочной).
- Доступ: пробные дни, выдача админом, опционально Telegram Stars.
- Контент живёт в БД, бот не генерирует разборы на лету — это быстрее, дешевле и педагогически контролируемо.

## Быстрый старт

1. Создай базу MySQL, например `tutor_bot`, с кодировкой `utf8mb4`.
2. Скопируй `.env.example` в `.env` и заполни токен, доступы к БД и свой Telegram id в `ADMIN_IDS`.
3. Установи зависимости и запусти бота:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

При старте таблицы создаются сами, школьная математика загружается в базу.

Пробный доступ задаётся `TRIAL_DAYS` (по умолчанию 3). Выдать месяц вручную:

```
/grant 123456789 30
```

Чтобы принимать оплату внутри Telegram, поставь `STARS_PRICE` больше нуля (цена в Stars).

## Масштаб

- Пул соединений MySQL (`DB_POOL_SIZE`, `DB_POOL_MAX_OVERFLOW`).
- Для нескольких процессов бота укажи `REDIS_URL` — FSM уйдёт в Redis.
- Поллинг удобен для старта; на нагрузке лучше webhook + несколько воркеров с общим Redis.
- Предметы и треки — отдельные сущности: математика/школа сейчас, физика, ОГЭ, ЕГЭ добавляются контентом, а не новым ботом.

## Контент

Темы и задачи — в `tutor_bot/content/math_school.py`. Формат ответа:

- `number` / `fraction` — число или дробь (`3/4` и `0.75` считаются одним ответом);
- `numbers` — несколько корней, порядок не важен: `2; -3`;
- `text` / `choice` — строка без учёта регистра.

Дальше логично вынести редактор тем в админку, не меняя хендлеры.

## Команды

| Команда | Кто | Назначение |
| --- | --- | --- |
| `/start` | ученик | регистрация и класс |
| `/learn` | ученик | продолжить |
| `/topics` | ученик | список тем |
| `/progress` | ученик | оценки |
| `/subscribe` | ученик | статус доступа |
| `/grant id дни` | админ | выдать доступ |
| `/revoke id` | админ | закрыть доступ |
| `/stats` | админ | число пользователей |
